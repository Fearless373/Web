# Restaurant Order App

A modern restaurant ordering system built with Next.js.

## Features

- Customer menu browsing and ordering
- Cart and checkout
- Kitchen display for order management
- Admin dashboard for menu and reports
- API routes for menu, orders, and reports

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Zustand for state
